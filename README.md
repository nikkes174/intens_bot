# Intens Bot — Telegram-бот для продажи тренировок

Telegram-бот для продажи трёх тренировочных протоколов и комплекта через YooKassa,
автоматической выдачей материалов и защищённым доступом в приватные группы.

## Возможности

- Glute Protocol (1 490 ₽), V-Shape (1 290 ₽) и Core Protocol (1 090 ₽)
- Комплект из трёх программ за 3 290 ₽ с общей выдачей материалов и доступов
- Оплата через YooKassa с webhook-подтверждением
- Автоматическая выдача материалов (видео, PDF, документы, фото, аудио, текст)
- Приватные Telegram-группы с заявками на вступление
- Админ-панель внутри Telegram (/admin)
- Статистика продаж
- Надёжная очередь задач (transactional outbox)
- Повторная выдача материалов

## Установка

### Локальный запуск

1. Клонируйте репозиторий:

```bash
git clone https://github.com/nikkes174/intens_bot.git
cd intens_bot
git checkout bulki_bot
```

2. Создайте виртуальное окружение:

```bash
python -m venv .venv
source .venv/bin/activate  # Linux/Mac
# или
.venv\Scripts\activate  # Windows
```

3. Установите зависимости:

```bash
pip install -r requirements-dev.txt
```

4. Создайте файл `.env`:

```bash
cp .env.example .env
```

5. Для локального запуска заполните `.env` своими значениями. Используйте локальный путь к БД:

```env
BOT_TOKEN=ваш_токен_бота
ADMINS=ваш_telegram_id
DB=sqlite+aiosqlite:///bot.db
YOOKASSA_SHOP_ID=ваш_shop_id
YOOKASSA_SECRET_KEY=ваш_secret_key
YOOKASSA_RETURN_URL=https://t.me/your_bot_username
WEBHOOK_HOST=0.0.0.0
WEBHOOK_PORT=8000
LOG_LEVEL=INFO
GLUTE_ID=-1001234567890
V_SHARE_ID=-1001234567891
CORE_PROTOCOL_ID=-1001234567892
```

Значения ID выше — примеры. Укажите реальные ID своих приватных групп: добавьте бота
администратором с правом приглашать участников, выполните `/chatid` в каждой группе и
перенесите полученные числа в `GLUTE_ID`, `V_SHARE_ID` и `CORE_PROTOCOL_ID` соответственно.
Переменная для V-Shape намеренно называется `V_SHARE_ID`. Пустые значения допустимы во время
разработки; соответствующая группа тогда будет недоступна. После изменения `.env` перезапустите
бота, чтобы загрузилась новая конфигурация.

Для Docker Compose укажите `DB=sqlite+aiosqlite:////app/data/bot.db`, чтобы база и очередь
отложенных сообщений сохранялись в подключённом томе.

6. Запустите бота:

```bash
python -m bot
```

### Docker

1. Создайте файл `.env` (см. выше)

2. Запустите через Docker Compose:

```bash
docker-compose up -d
```

3. Проверьте логи:

```bash
docker-compose logs -f bot
```

При запуске бот применяет Alembic-миграции и создаёт каталог продуктов. Данные SQLite
хранятся в томе `bot_data`.

## YooKassa Webhook

1. В личном кабинете YooKassa укажите URL webhook:

```
https://ваш_домен/webhooks/yookassa
```

2. Убедитесь, что бот имеет публичный HTTPS-адрес (например, через ngrok или сервер)

3. YooKassa будет отправлять уведомления о событиях:
   - `payment.succeeded` — успешная оплата
   - `payment.canceled` — отмена платежа

## Telegram-группы

1. Создайте приватный канал или группу для каждого протокола (Glute, V-Shape и Core).
2. Добавьте бота администратором с правами приглашать пользователей и одобрять заявки.
3. Выполните `/chatid` в каждой группе и внесите ID в `GLUTE_ID`, `V_SHARE_ID` и
   `CORE_PROTOCOL_ID` в `.env`.
4. Перезапустите бота. При старте он проверит доступ бота к каждой настроенной группе.

ID этих трёх групп задаются только через `.env`; изменить привязку в админ-панели нельзя.
Остальные legacy-тренировки могут использовать сохранённый в БД `chat_id`.

## Отложенные сообщения

Сообщения через 24 часа, 72 часа и 7 дней хранятся в БД и атомарно захватываются воркером.
Постоянные ошибки (например, блокировка бота) не повторяются; временные ошибки Telegram
повторяются ограниченное число раз, а последняя ошибка сохраняется в задании.

Telegram Bot API и фиксация статуса в БД не образуют общую транзакцию. Если отправка могла
пройти, но результат не удалось записать, задание переводится в `failed` и автоматически не
отправляется повторно, чтобы снизить риск дубля. При потере сетевого ответа результат также
считается неоднозначным. Это исключает автоматическую exactly-once гарантию: в таком случае
сообщение может потребовать ручной проверки.

## Админ-панель

1. Отправьте `/admin` в бота
2. Доступные разделы:
   - Управление тренировками — изменение названий, описаний, цен
   - Материалы тренировок — загрузка и управление файлами
   - Пользователи и покупки — поиск пользователей, история заказов
   - Статистика — продажи, выручка, отменённые заказы

## Миграции БД

```bash
# Создать миграцию
alembic revision --autogenerate -m "описание"

# Применить миграции
alembic upgrade head

# Откатить миграцию
alembic downgrade -1
```

## Переменные окружения

| Переменная | Описание |
|---|---|
| BOT_TOKEN | Токен Telegram-бота |
| ADMINS | ID администраторов (через запятую) |
| DB | URL базы данных |
| YOOKASSA_SHOP_ID | ID магазина YooKassa |
| YOOKASSA_SECRET_KEY | Секретный ключ YooKassa |
| YOOKASSA_RETURN_URL | URL возврата после оплаты |
| WEBHOOK_HOST | Хост webhook-сервера |
| WEBHOOK_PORT | Порт webhook-сервера |
| LOG_LEVEL | Уровень логирования |
| GLUTE_ID | Chat ID группы Glute Protocol |
| V_SHARE_ID | Chat ID группы V-Shape |
| CORE_PROTOCOL_ID | Chat ID группы Core Protocol |

Для чеков самозанятого сервис передаёт YooKassa код НДС `1` («без НДС»); отдельная
переменная `YOOKASSA_VAT_CODE` не нужна.
